# 0.0.2 验证记录 · 2026-10-04

- 设备升级编号 4，公开显示版本 0.0.2；构建不自动递增。
- 原有图像在 RGB565 色值上无损转换为 INDEX8，163 色加透明索引。图集为 512×359、183808 字节；调色板 328 字节。Host init 直接读取签名资源并驻留，Guest 不逐帧读取精灵。
- 声音资源偏移和 PCM 数据保持一致；图集追加到原有 294442 字节资源之后，资源总量为 478578 字节。音效、宿主静音、触摸/KEY1、重试阈值和最高分保存沿用原有行为。
- 加速路径不分配 108578 字节 Guest 画布；正式 Wasm 初始线性内存 1 页（65536 字节），最大 4 页。缺少 SPRITE 能力时，init 扩展线性内存并使用原有完整图像与 draw_clear。
- 独立原生参考解释器对照准备、飞行、结算 108 个场景，逐像素一致，包括管道翻转/裁剪、地面滚动、数字和奖牌。
- 输入生命周期、取消、失败重试保护、实际穿管计分、最高分保存和时钟回绕回归通过；真实 WAMR 解释器 14 秒输入脚本通过。
- 使用实际 core 条带渲染器的驻留精灵截图，与仅旧 import 的对照构建在 0/32/9900/14000 ms 的 PNG 像素逐字节一致。桌面 WAMR 的 Guest heap_bytes 为 98869，对照旧路径 228562；此指标不包括 Host 驻留图集。
- 新 import 要求匹配固件；旧 import 独立构建可设置 BIRD_LEGACY_GRAPHICS=1。桌面验证不能代替设备性能或音频验收。
- 宿主新增驻留图集的内存成本为约 184 KiB；Guest 内存减少不等于整机总内存减少。S31 硬件仍待验证；S3 送屏完成率见下文。

## S3 真机验证 · 2026-10-05

revision 4 已真机 AOT 安装，selected_backend=2、fallback_reason=0。最终 build13 的 60 秒动态测量为真实面板 21.17–21.78 FPS、获取 24–26 帧/秒、宿主原生绘制约 18.5 ms，证据为根仓库 `tmp/gfx-bird4-smallstack-active-bench.log`。旧 revision 3 完整图像基线约 16.9 FPS。早期加速版本的 7.4–8.4 FPS 回退已由宿主整数倍率、小栈及行复制优化解决，不将早期结果当成最终表现。

转换器按 alpha≥128 自动生成通用 opaque 元数据，完全不透明精灵不设置 TRANSPARENT。背景 233×233 和地面 168×56 的图集索引零数量均为 0。原生 108 场景及真实 core 0/32/9900/14000 ms 截图前后像素完全一致。最终同 ID revision 4 包为 656700 字节，SHA-256 `2fc9d0da6e1af5043c4d48b14a9a18133194c246c8f24ba618829a2dd21b7fe0`，本轮宿主优化未更改已安装 Guest 包。

每完整帧提交一次背景；其余三个时钟保留既有四次回调节奏，没有重复四份精灵。整机驻留图集成本约 184 KiB。S3 性能回归已有证据，S31 实物、人工触摸手感、音量和长期运行仍未验收；授权状态保留 unverified。
