# 更新日志

## v3

- 扩充为四个主题八个原创关卡：草原、洞穴、云海、熔炉，终关对战熔核魔像。
- 新增弹簧、水平与垂直移动平台、岩浆，以及黄蜂、跳虫、刺背虫三种敌人。
- 新增护盾能量核，可挡一次碰撞或尖刺；每 50 颗宝石奖励一条命。
- 自动保存进度，标题页可选择已解锁的关卡。
- 主题按关切换调色板和背景；新增护盾、弹簧、Boss 音效。

## v2

- 支持 pogo 外设手柄：十字键或左摇杆移动，A 起跳（按住跳得更高），START 开始或重开；接上手柄后不再读倾斜。
- 游戏中拔掉手柄自动暂停，点屏幕或按 A 继续，之后恢复倾斜与触屏操作。
- 需要支持手柄事件的固件。

## v1

- 首个版本：原创横版平台跳跃，一整关含检查点、宝石箱、木桥、尖刺和传送门终点。
- 倾斜 IMU 或按住屏幕左右侧移动，点按中间起跳，按住跳得更高；KEY1 留给宿主返回。
- INDEX8 图集一次上传，每帧提交 TILEMAP 可见窗口与精灵；33 ms 固定步长。
