# 内容来源

游戏代码、关卡与气球、地面、终点等图形由本项目编写和绘制。机器人「豆豆」、黄蜂和云朵的像素画来自本仓库的 Pixel Quest 示例；所需字符画已直接放入 `prepare_assets.py`，生成时不依赖其他示例目录。

游戏文字由生成脚本使用本机安装的 Microsoft YaHei 绘制，未随示例分发字体文件；修改或重新分发时请自行确认适用的字体授权。

`cover.png` 使用内置 ImageGen 单独生成，再缩放为 210×210 RGB 方图。画面主题为原创机器人随红、黄气球飞向云端，天空铺满四角；它不是游戏截图。

未使用《New Super Mario Bros.》的角色、美术、音频或关卡数据。发布方应在对外分发前确认各项内容的权利状态。
