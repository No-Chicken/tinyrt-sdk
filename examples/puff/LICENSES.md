# 内容来源

游戏代码、关卡、玩法和全部图形由本项目编写，像素图、首领、道具、背景和音效都在 `prepare_assets.py` 中用代码绘制和合成，生成时不读取任何外部图片或音频文件。

游戏里的文字是用本机安装的 Microsoft YaHei 渲染成字形表后打包的，未随示例分发字体文件；修改或重新分发时请自行确认适用的字体授权。

`cover.png` 沿用 v2 的 210×210 封面（内置 ImageGen 生成，原创机器人随气球飞向云端），不是游戏截图。主角豆豆的像素画也沿用 v2（源自本仓库 Pixel Quest 示例）。

游戏玩法、角色、关卡和美术均为原创，未使用任何其他游戏的角色、美术、音频或关卡数据。发布方应在对外分发前确认各项内容的权利状态。
