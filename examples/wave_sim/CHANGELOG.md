# Changelog

## v8

600 个立体球使用透视投影、16 级深度桶和预生成高光图集；17/17/16 ms 时钟平均 60 Hz。
紧凑粒子状态与连续邻居网格降低计算开销，前后位置并集用于擦除旧画面。
保留 OCEAN、NEON、TOXIC、LAVA、MONO 和 500 ms 长按换色；触摸取消不触发动作。
板级 IMU 安装方向由固件统一，应用使用同一坐标约定。ABI 仍为 1。

## v7

新增宿主 GRID 与调色板绘制。正式 20×20 网格、130 粒子配置每帧索引 400 字节，完整几何 1484 字节；40×40/400 粒子可覆盖构建比较。
支持能力时不分配 Guest 的 108578 字节 RGB565 图像；缺少能力时使用旧完整帧路径。
完整绘制记录配合保守变化区域刷新；主题切换全屏，无像素变化跳帧。连续画布回放覆盖合并帧和提示消失。
保留 60 真实步/秒、H=1/30、五主题、S3/S31 轴向和输入阈值。两种网格配置的五主题、36 方向与旧绘制完整像素一致；真机记录见 VALIDATION.md。

## V1

新增圆屏像素流体应用、五套主题、掀浪与触摸长按换色，配套桌面预览工具。
