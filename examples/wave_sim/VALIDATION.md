# Wave 0.0.2 验证记录 · 2026-10-05

正式应用为 `demo.wave-sim` revision 7，配置 `WAVE_GRID=20`、`WAVE_N=130`。物理以每秒 60 个真实步、H=1/30 推进，保留五主题和五类控制。源码默认 40 网格，`WAVE_GRID=40,WAVE_N=400` 可覆盖构建用于比较；构建不自动增加版本。

## 图像和回归

20×20 GRID 索引为 400 字节，CLEAR、网格、方向环和标记合计 1484 字节。逻辑单元为 10 像素，灯面 9 像素、间隔 1 像素，宿主放大两倍。加速路径不分配 108578 字节 Guest RGB565 图像；能力不足时动态分配旧完整帧缓冲并保留 clear 语义。初始线性内存为 64 KiB，最大四页。新 import 需要匹配宿主；面向旧宿主应以 `WAVE_LEGACY_GRAPHICS=1` 构建。

原生七配置回归覆盖 40 网格普通、metrics、S31、400 粒子比较，以及 20/130 普通、metrics、S31。每配置验证五主题×36方向的完整像素一致、36000 次摇动后的有限值和边界、完整与分片推进一致、输入取消、500 ms 阈值、按键长短按和时钟回绕。真实桌面 WAMR 的普通与 metrics 六秒脚本通过。40/400 覆盖配置在 0/990/3000/6000 ms 的截图与此前 CLEAR 版本相同；粗网格加速与旧绘制也通过独立像素比较。

## S3 真机证据

正式 20/130 包使用 AOT，`selected_backend=2`、`fallback_reason=0`。此前正式包真实面板为 19–21 FPS，证据为根仓库 `tmp/gfx-wave20-final-active-bench.log`。

宿主改用内部 SRAM 条带后，`tmp/gfx-wave20-sram8-active-bench.log` 的持续倾斜窗口为 21.36、24.26 FPS，平稳及主题窗口为 27.07、26.96、26.88 FPS。当前可描述为约 21–27 FPS；持续倾斜仍未达到 25 FPS。重启后 32 行内部缓冲均成功分配，8 行回退未触发，因此这次测量不能证明 8 行路径的速度。宿主原生绘制约 22.3 ms。

软件注入传感器的四方向及五主题通过：各方向四秒后质心约右(1491,818)、左(406,884)、上(1098,422)、下(906,1514)，主题为 NEON、TOXIC、LAVA、MONO、OCEAN。完整证据同上两份 active-bench 日志。这属于传感器注入验证，本轮没有人工倾斜测试。S3 配置为安装角 180°、X 正向、Y 反向；S31 为安装角 0°、X 反向、Y 正向，仅有原生回归证据。

## 同 ID 临时测量

`tools/build_debug.py` 仅在 SDK `build/diagnostic-wave` 生成临时清单，保留正式 app ID、revision 和网格/粒子配置，只增加 `WAVE_METRICS=1`。临时替换同一个 Wave 应用，测量后恢复普通包；不安装额外诊断应用。同 revision 替换通过开发控制台移除该 ID 后重新安装。

20/130 临时 metrics 的 `tmp/gfx-wave20-physics-render-metrics.log` 记录 P≈8.3 ms/物理步、R≈0.7 ms/Guest 组合、提交 FPS≈24。早期 40/400 临时测量为 P≈11.7 ms、R≈1.8 ms。计时分辨率为 1 ms，P/R 不含宿主绘制和传输；metrics 文本本身有开销，提交 FPS 不能作为普通包真实面板帧率。

## 发布限制

后续局部刷新优化仍提交完整独立记录，首帧及主题变化全屏；其他帧以单个保守矩形覆盖变化灯面、旧新方向标记和提示的出现/消失。无像素变化调用 draw_skip，物理频率保持原配置。原生连续 240 场景画布回放验证三帧合并、快速运动、主题变化、提示消失和无变化跳帧，与完整帧画布一致。此前 21–27 FPS 为这项优化之前的数据。局部刷新后的 60 秒实测见根仓库 `tmp/gfx-wave20-damage-active-bench.log`：左右持续倾斜为 218/10.040238≈21.71 FPS，上下为 282/10.086959≈27.96 FPS，平稳及主题窗口为 303/10.009≈30.27、302/10.011538≈30.17 FPS。左右持续倾斜仍未达到 25 FPS，不能宣称所有场景达标。此次 8 行内部 SRAM 缓冲全部命中，回退路径已实际验证；原生绘制平稳约 7.9 ms、倾斜约 21.1 ms。后续横向裁剪的阶段结果如下。

发布资料保留授权状态 `unverified`；正式 ZIP 使用最终 core 与 SDK 提交生成。真机输入手感、S31 实物轴向及长期运行仍需补充证据，不把桌面或软件注入结果等同于人工操作验收。

## 横向裁剪阶段 · build12

根仓库 `tmp/gfx-wave20-region-active-bench.log` 保存横向 region 渲染的 60 秒记录。首窗混入 Bird 约 140 ms 绘制，应剔除，不能作为 Wave 稳态样本。稳态 APP_PERF 435531 的获取率为 280/10.307213≈27.17 FPS；真实 PANEL 442985、452998 的连续倾斜完成率为 295/10.009500≈29.47、296/10.012580≈29.56 FPS。平稳窗口为 304/10.008920≈30.37、304/10.009499≈30.37、303/10.009≈30.27 FPS。

该阶段连续倾斜达到 25 FPS；后段原生绘制约 4.999 ms/帧，16 行内部 SRAM 缓冲全部命中。四方向软件注入、五主题和短按通过，AOT selected_backend=2、fallback_reason=0。Wave 算法和包未改变；最终固件仍有 Bird 修复，build13 最后稳态结果见下文。此处仅记录已测阶段，不据此生成最终 ZIP。
